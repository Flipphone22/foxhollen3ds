# foxhollen3ds

A WIP N3DS and O3DS port of fox hollow. Builds as both a 3dsx and CIA. I've played and validated up until the second krozoa spirit, though the game does still have issues, ranging from graphical issues, to random crashes. The o3ds-fast graphic preset is the best tested, N3DS-fancy is essentially the opposite and turns on everything. This appears to interfere with the N3ds's built in streaming as much my play through testing stream looks like a pixelated mess, but you can see gameplay of it here.
