## 2. Rejected or failed experiments (do not repeat)

**Renderer and shaders**
- **Coarse water and wake grids.** Pixel error of coarse grids was often closer to wrong than to omitting the effect. Measured mean RGB/p95: 4.406/33.36 with no offset, 4.704 at 306 tris, 3.748 at 1122, 0.677 at 4290 (L15293-15296). A regular wake grid gave p95 offset errors of 30.17 texels at 256 tris and 13.41 at 4096 (L15439-15440). Do not add dense meshes (17160 or 68640 tris) based on coordinate error alone (L15336-15338). Ripple meshes cost up to 411240 tris/frame in the worst case, so do not admit them blindly (L15214-15215).
- **Camera-space palette / view poses.** In a clean pair the guest held 59.83 FPS on both builds, and render CPU rose 7.460->7.542 ms (+0.082). No net gain, so it stays unpromoted. Do not promote based on shader instruction counts (L15458-15466).
- **Specular demand.** Render CPU rose by 0.054 ms/frame (16.7137->16.7115 ms frame), with no FPS win. Held as an experiment. Next idea is scene-level batching (L15672-15694). Docs: NATIVE_SPECULAR_DEMAND.md.
- **Specular prefetch.** Avoids 253/250 half copies, but the cost gate is open and it is not accepted (L15618-15622).
- **Directional and signed-colour normal-demand** experiments were already rejected on 12 Oct (L15542).
- **Actor vertex alias / exact-sharing audits** found ZERO full-reference duplicates (835 models). Do not add a runtime optimizer for this (L15520-15523, L17541-17544).
- **Exact texture repack:** 85 RGBA8 images would save about 1.08% of GPU bytes. Not an FPS route (L17488-17491).

**Geometry reduction (ISO)**
- **Native geometry reduction** removes only 1682 of 1383658 tris (0.12%). It is not an effective fast preset and must not replace the deployed performance assets (L18766-18781).
- These all gave no meaningful gain: witness locks, component refinement, 20-degree orientation (L18012, L18088-18091), the small-component reducer (L17915), reduction regions (only 6-30 extra tris, L17861-17886), and world refit with meshopt simplifyWithUpdate (best 0.61%, L17546-17559). Stop sweeping these parameters.
- Do not weaken the bone, morph or UV guards.

**Texture and movie codecs (ISO)**

  - Fidelity triangle-invariant cache: no gain and +14336 B stack (L17228).
  - Plane-bound: 0.23% (L16861). Channel-histogram: 3.3% slower (L16861).

## 4. Architecture and engine facts

**Original game**
- `gNewShadowBumpTexture` is a STATIC procedural 64x64 RGB5A3 texture, generated once in newshadows.c `allocLotsOfTextures` (lines 1775-1870). It has no per-frame producer (L15262-15268).
- The source Ripple uses A/B offsets plus G coverage (GX_ITBA_U) and UV 127/128. The wake uses B/G/A with full UV, so the two are not interchangeable.
- `loadReflectionTexMtxs` uses CameraLightPerspectiveScaledMatrix and FlipYMatrix, each concatenated with CameraModelView. `Camera_LoadModelViewMatrix` removes and restores the map offset (L15414-15417). Do not run the retired lightmap DrawTriangleList.
- `camcontrol_findBestTarget` uses the hit-volume centre, range, height, flags and visibility. The Thorntail interaction centre is z=-45 with radius 48 (L15944-15946, L15924).
- Original `Camera_ApplyDecalViewport` sets near -.05 and far 1 before projected shadows (L15899).
- The desktop Aurora shader.cpp blur uses floating /2.0 (L16057).

**PICA, SDK and memory**
- When a D24S8 depth buffer is sampled as RGBA8, G holds the high depth byte, with orientation 1-G (L16092).
- SDK target deletion inside a frame panics, so create targets last (L15964).
- The SDK already emits framebuffer flush/invalidate and texture-cache clear (L15863).
- Shared fog uses uniform slot 94 (c94 ABI) (L15408, L16207).
- Shader code size must stay under 512. `build.json shader_budget445` is generic; the active native count is 439 (L15508, L15585).
- Float24 in the VM uses a float32 ALU, so VM error bounds are not physical bounds (L15493).
- **Budgets:**
  - New: heap 71303168, linear 25165824.
  - Old: heap 50331648, linear 10485760.
  - VRAM free is about 4.69-4.72 MB; the stack reservation is 524288.
  - Process memory: New ~103.3 MB of 130023424; Old ~67.7 MB of 83886080.
  - Old linear free is only about 2-3.3 MB.
  - Post effects have a guard of 1 MiB VRAM / 15% linear.
- The memory panel shows USED values: 6795/24576 KiB linear and 1531/6144 KiB VRAM. An earlier "missed allocation" claim was a misreading (L15886-15889).
- New core2 is already used by audio. The startup worker borrows core2 only during prepare and joins before menu or gameplay (L17348).
- Azahar lacks SVC 0x11 GetCurrentProcessorNumber, so core 0 is not proof of affinity. The 804 MHz flag is reporting only; do not scale timings by 3x (L16784-16787).
- The SDK JPEG decoder requires `-fshort-enums` (L18716).

**ISO data**
- The ISO is 1459978240 B with SHA f5e5a9...
- Geometry: 109 banks, 4613 records, 2110 unique models (2102 rendering).
- Textures: 19264 records, 20208 planes, 2454 unique textures, giving 3754 variants and 2918508 ETC blocks.
- Movie: 1797 frames, 1787 unique.
- The texture pack is capped at a 128 KiB directory and a 128 MiB file. The raw native total of 169.5 MB would exceed this, so compression is mandatory.
- 210 NPOT CMPR images are padded: 185 pass RMSE 14 and 25 stay RGBA8 (L18217-18221).
- Sky UV fault: it implicates the specular UV branch/control. Do not move light7 to b15 globally (L18705-18707).
