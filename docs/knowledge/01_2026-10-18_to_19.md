## 4. Architecture and engine facts

**Memory budgets** (sampled values; transient peaks may be missed):
- Old: heap 41.37/49.28 MB, linear free 3.67/12.58 MB, VRAM free 4.72 MB, stack 73008/524288, process 70.7/83.9 MB (L154-155).
- New: heap 54.18/71.30 MB, linear free 17.1/25.2 MB, VRAM free 4.69 MB, process 104.8/130.0 MB (L2470).
- "Old80/New124" are verified build profiles in every build check.

**Image and material allocation:**
- The image loader checks staging against a shared 512 KiB material cap and a normal-heap 85% headroom rule before allocating linear memory.
- The unique resident image cap is 4 MiB, with a 15% linear reserve (L2713-2723, L2751).

**GPU / PICA:**
- There are 21 embedded GPU programs. The adaptive glow shader adds one (173-174 stored instructions, 42 float registers), and the particle common bank adds one (503/512 instructions) (L3583, L1197).
- Picasso constant arrays use descending registers, so indexing them needs a negative index (L1287).
- GPU pending time (14.7 ms) overlaps CPU work; it is not additive (L631).

**Glow particle meshes:**
- The 128-triangle default has a 130-vertex cap with 16 B vertices and a 2856 B output.
- Scratch is 67600 B for 4225 training samples.
- Pages hold four flip variants each, at 11424 B per page.
- The original layout holds 5 pages in 57120 B; packed, they take 37920 B (-33.6%).
- Residency is capped at 64 KiB linear plus 15% headroom (L3623-3626, L3349-3361).
- The source reflection GS needs the sequential signed alpha across the four corners before interpolation (L3717).

**World rendering:**
- Secondary world streams enqueue effects, not ordinary transparent draws.
- `passSelect` 0 hides 2. The water flag 0x80000000 wins over 0x40000000 and 0x2000 (L2975-2977).
- A whole-run palace log counts 53972 world draws, 37364 packet draws (10052 calls, 41 groups) and 25419 actor draws (L407).

**Models and skinning:**
- Of 829 unique models, 51 are skinned, with 1008 chunks (at most 52 per model) (L706, L1133).
- `ObjModel_RelocateAnimData` initializes output offsets and weight pointers. Skin plans must be published after it runs, not at registration (L601, L883).
- The model resource content version changes on every geometry write, so it cannot serve as a plan lifetime (L681).
- Native morph capture happens before the CPU skin overwrite (L1162).

**Audio:**
- Output deadline misses are not the same as missing source submissions (L801-806).
- Azahar HLE `mixers.cpp` hardcodes `dropped_frames=0`, so drop conditions need LLE or injected coverage (L807).

**Movies:**
- Synchronous `DVDRead` busy-polls. In the cockpit, 36141 of 36149 `padUpdate` calls come from DVDRead polling.
- The `<=1 ms` event wait cut polls to 141 (L2809-2820).

**Save system:**
- A normal save does not move the checkpoint. Only the authored op31 `savePoint` trigger updates the stored position (L1669, L2528-2531, L2562).
- `mainGetBit` treats 149 as a constant TRUE and 150 as FALSE; bit 0x8000 means inversion (L2100).

**Collision map:**
- `rom=(cell>>23)&255`, `local=(cell>>17)&63`, `block=TRKBLK[rom]+local`. A value of 255 means absent.
- Vertices are signed, shifted `>>3`, then `collisionYOffset` is added; the grid unit is 640 (L1785-1787, L1806-1810).

**Headers:** the root headers differ from the generated ARM structs (for example, SnowHorn state is 0x488 in the ARM build vs 0x48c in root). Always derive offsets from the archived ELF DWARF (L2034-2037).

**Particle update cost** (exact DWARF partition of 1433744 encounters):
- Lifetime, physics, callbacks and scale: 399920.
- World position: 246852.
- Bounds: 148884.
- Colour, UV and shape: 177016.
- Unattributed: 206886 (L1012-1014).
- Alpha and UV together are under 1% of main, so tweaking them is not a route to 30 FPS (L427-433).

**Live particle state:** 151 of 151 sampled pools had homogeneous flags, and 80.43% of slots match the direct-world mask. This is not a proven invariant (L252-254).

## 5. Tooling and workflow

**Building:**
- Never blind-build the root WIP. Use the isolated builders (`build_*.py`, and `build_native_matrix.py` per AGENTS).
- Each build checks: all GPU programs, the game archive hash, Old80/New124, the unchanged setup recipe, and root/archive restoration.
- The `/build` generated cache can differ from the archived generated source. Use the archived TU with its MD5 verified (for example, `98dcf788...` for expgfx) (L1009-1010, L464).

**Deploying:**
- `package_console_setup.py` builds the package. The direct FTP install stages all six payloads, verifies every byte, renames with backups, then rereads the final manifest using `--single-readback`.
- On the console: `SD:/3ds/foxhollow/foxhollow.{3dsx,cia}`. The CIA needs FBI installation.
- `RUNTIME_REJECTED.json` makes the packager refuse to redeploy that build (L545-548, L847-848).
- FTP to New223 often times out before login. Do not loop retries, and do not overwrite a pending hardware test (L2059, L2229-2231).
- The user has standing authorization for uploads. Only ask whether the console is available, and do not repeat the question (L1356-1357).

**Measuring:**
- Instruction encounters are not cycles or FPS. Emulator-displayed FPS (for example 59.9) is not console evidence (L3489).
- Foreign SMG Azahar emulators share the host, so wall timing is excluded. `host_timing_context.py` records per-task CPU (L1166-1178).
- The frame gate uses 8 object updates plus 8 particle updates, not present calls; the actual present count is 17 or 16 (L444-445).

**Gotchas:**
- Windows Python 3.7 lacks `removesuffix` and `math.dist`; use WSL Python 3 (L633, L3063).
- pyelftools needs `relocate_dwarf_sections=False` (L2034).
- Do not overwrite existing tools with AddFile or reuse established artifact directories (L40-41).

**Rescue harness:**
- Tools include `run_rescue_*.py`, `drive_snowhorn_rescue.py`, `drive_rescue_queue.py` with `{save:true}` support, `append_console_hid --after-last`, `hid_pulse_schedule` (1-12 pulses, at most 180 retraces), `inspect_native_objects`, `inspect_native_menu` and `verify_rescue_checkpoint.py`.
- Inputs are ordinary HID only. Never write to guest memory.
- Poll the same live handles rather than restarting on a timeout (L1341-1359, L1680-1696).
- Disk cleanup on 18 Oct deleted 9058 pre-17-Oct XWD captures after PNG validation (L1265-1271).
