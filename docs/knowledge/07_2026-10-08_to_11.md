## 4. Architecture and engine facts

- **PICA/SDK:**
  - VSH float-uniform writes alias GS registers when GS is non-exclusive, so CPU shadow state does not equal device residency (L25842). The GS constants sit at c87..95.
  - C3D_BoolUnifSet needs the queried location 0x68 (L26160).
  - C3D_BindProgram shares code only for the same DVLP pointer (L23478).
  - The SDK dirties state on every TexBind (L23618).
  - Picasso pads outputs automatically (L23416).
  - The combined shader limit is 512 instructions; the main shader is at 511 (L24063). Fur is a separate 214-instruction program (L24159).
  - Azahar software-processes GS and overestimates hardware (L25867, L25718).
- **Original game:**
  - Fur interpolates STQ with a fragment divide (L23411).
  - addShaderLayerStages defers lighting whenever reg1 OR reg2 exists (L24891).
  - Zero light mask disables lighting, which gives white (L23346).
  - Opaque SH_FernTree uses a fixed alpha threshold of 64 (L23958).
  - The original cockpit has green illumination, so a green tint alone is not a bug (L24045).
  - EnterSaveNameScreen scroll is per update without timeDelta, so replays must record every clock step (L25702).
  - The purple creature is HagabonMK2 (L25708).
  - Specular comes from rcp_dolphin sun/moon 32x32 hemisphere maps (L25301).
  - Fog order: heavy height fog comes before fade, and GX distance fog comes after all TEV stages (L25187).
- **Memory budgets:** Old CIA 80 MiB, New 124 MiB (Old 96 MiB is also a valid mode, L26239). There is a 15% reserve on normal, linear and process memory.
  - Typical New peaks: heap 48.4/71.3 MB, linear free 18.5/25.2 MB, process 103/130 MB.
  - Typical Old peaks: 40.8/50.3 MB, linear free 3.8/10.5 MB, process 67.6/83.9 MB.
  - VRAM free is 4.82 MB and the measured stack is about 73 KB of a 524 KB reservation (L22847).
  - With original assets, Old linear free drops to about 1.8-1.98 MB, which is tight (L23319, L24122).
  - The native image pool is 4 MiB on both (L25986).
  - In the resource log, `resident_bytes` means capacity; use memory.jsonl for actual residency (L23120).
- **Cores:** New core 2 is already used by audio. Do not assume two idle graphics cores (repeated, for example L23176).
- **Asset packs:** the original pack is 51,010,084 B and its cache 22,875,803 B (L24108). The actor 22-bone repack keeps geometry exact and reduces groups from 716 to 431 (L24216).

## 5. Tooling and workflow

- **Building:** never blind-build the worktree. The six native-image VRAM WIP files must be isolated and then restored, using the build-*-vN helpers and source-snapshot + libgame.a (repeated, for example L23086). Pure patch tools (`pica_*_patch.py`) are already applied to stable and WIP, so never double-apply them. The normal builder wrongly prints a "console-replay" label; the actual variant is console (L23615).
- **Deployment:** `install_visual_settings_update.py --variant both|normal|replay` stages, reads back, renames and checks sizes. It reuses unchanged original assets via prior byte proof (L23325, L23943). CIA installs need FBI; the 3dsx runs from HBL. Old FTP needs a LIST fallback because SIZE is unsupported (L25650). `ftp_stage_verify.py` resumes with REST (L26147).
- **Collection and headless runs:** `collect_visual_console` takes `--gpu-inputs` / `--io-history`. Do not re-collect logs that have not changed (L23514). `run_console_headless` takes `--pica-layout-audit`, `--native-image-vram`, `--native-draw-capture` and `--graphics-settings-dir`. The custom Azahar layout-audit build caught the real fetch fault (L24954).
- **Gotchas:**
  - A full disk caused failed runs; ELF hardlink deduplication recovered 12.5 GB, and the runner now preflights disk space (L23683-23689).
  - `analyze_arm_blocks.py` needs WSL (L25852).
  - Do not ask the user to transcribe crash screens; Luma dumps are collected automatically (L24746, L24707).
  - Before testing another performance candidate, check port-experiment-decisions.json (AGENTS.md).
- **Cost gates:** optional families get 0.20 ms on New and 0.50 ms on Old (first defined for specular, L25207). Fur shells get 0.5 ms on New (L24183). Height fog later used 0.5 ms New / 1 ms Old (L23109). The particle-stage allowance was +0.30 ms work / +0.15 ms submit. `compare_native_replay.py` enforces matched windows (L25940).
