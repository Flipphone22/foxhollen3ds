## 4. Architecture and engine facts

- Memory (Old normal): heap about 40.4-41.4 MB of 49283072, linear free 2.5-3.6 MB of 12582912, VRAM free 4723712, main stack about 73 KB of 512 KiB, process about 70.6 MB of 83886080. New: heap 54.2 MB of 71303168, linear free 17.1 MB of 25165824. Global 15% linear reserve, 4 MiB scene metadata, 6 MiB GPU caps, 4 MiB image budget. Old80/New124 entitlement. Heap tier is 47+12 because of the 8777728 preheap commit (L7406).
- The libctru `__libctru_exit` unmaps the linear and normal heaps BEFORE svcExitProcess and does no worker join. A panic calling exit(1) with live workers is therefore a late-exit hazard, and the fatal path uses svcExitProcess directly (L5554). In libctru 2.7, threadJoin returns early for finished threads before kernel retirement, and threadExit frees detached storage, so you need a kernel wait plus threadFree (L6565).
- The NDSP service waited indefinitely on IRQ/sleep while the owner joined without waking it. Fixed with a sticky stop event (L6131).
- Azahar SVC11 GetCurrentProcessorNumber was a stub that returns 0, so "failed-audio-core-placement" raw status is expected. Core placement is proven by an independent exact-ELF execution audit instead. The corrected emulator c3baca361fbc implements SVC11 (L6461).
- PICA/GPU: software PICA texture addressing inverts T (rows run bottom to top) (L4301). Do not reintroduce the mask Y-flip (L5164). Azahar GLSL rounds combiner output BEFORE scale (L4481). Indirect sampling is round(255*sample.abg) with STU bias -128; IA8 A routes to S and I routes to T (L4380). Index runs are bounded to 65532 per draw by heat-path convention (L4280). The stock C3D_TexBind dereferences NULL units 1/2. The stock gxqueue overflows at 96 aux calls per frame, and the game reserves 32 KiB for aux command storage (L3966, L3991).
- Original game: lightmap.c refreshes reflection textures early, conditional on HUD visibility, and blur and heat run after that. Distortion must not replace or invalidate shared raw depth (L4028). updateReflectionTextures captures 320x240 RGB565/Z8; native capture is 512x256 (L4215). The colour filter can run twice per frame around viewfinder draws, each needing a fresh capture (L4789). Camera_RebuildProjectionMatrix also updates four global camera matrices, so the call must be kept (L4196). Natural sepia needs CHEAT_SEPIA_MODE (L4722). The particle pool has 25 slots, not 32 (L6319). Lightning strand updates the caller's RNG seed via a pointer, so bolt CPU cannot be skipped when particles are off (L6531). modelApplyBoneTransforms is sparse morph composition, not skinning; CPU skinning is about 2% (L5902).
- Original capture maps quad edges to outer texel centres, which causes a 1-px shift. Mapping to native texel edges fixed it (L4061).
- Shader banks: the common actor/HUD/particle bank holds 501-509 of 512 instructions. Program configure copies 369216 B per 8 frames. Main memcpy is about 172 KB/frame, 7.56% of encounters (L6921).
