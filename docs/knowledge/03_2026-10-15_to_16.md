**Collision:** do not re-enable the old plane cache or the per-group bitset cursor (L8807). Do not blindly cache triangles, because terrain vertices, offsets and group flags can change at runtime (L7628-7630).

**Audio:**

## 5. Tooling and workflow

**Building:**
- NEVER blind-build root WIP. Each change has an isolating `build_<feature>.py` (for example build_audio_depop_sparse, build_program_resident.py, build_world_packet_local.py) plus a pure `*_patch.py`. These apply to an archived parent snapshot and restore root/archive afterwards.
- Integrity checks on every build: Old80/New124, 18 GPU programs, game archive hash.
- Packages go in `build/console-validation/foxhollow-iso-setup-<sha>.zip`.

**Run and profile:**
- `run_unified_startup.py`: `--profile` (allowed with LLE), `--cost` (disables layout instrumentation and captures), `--audio-native` / `--audio-cpu` (L8881, L9210, L8915).
- `compare_unified_cost.py`, `compare_last_hardware_work.py` (same-emulator comparison against the last physical build) (L7977).
- `analyze_arm_source.py` (DWARF MD5 exact match), `analyze_arm_call_sites.py`, `analyze_arm_blocks.py`.
- The standard profile window is scheduler frames 1300..1307, an 8-frame ARM instruction-encounter window. These are NOT cycles or FPS.
- Hooks must be installed BEFORE translation (persistent hook). Toggled hooks miss cached code (L11110-11115).

**Gotchas:**
- Windows checkpoint CRLF vs normalized comparison failure (L7884).
- A test-PASS "R0 failure" in the watermark JSON is incidental (L8206).
- The older `owner_bytes` telemetry omits the 1924B and 32B delays. Use the process/heap numbers instead (L8996).
- Emulator host timings with DSP LLE or capture are always EXCLUDED from performance claims.

**FTP and deployment:**
- Old is .229 and New is .223.
- Frequent failures: timeouts before login, and data connections resetting after login succeeds. The fix is for the user to fully relaunch ftpd (L9358-9374).
- Transfers stage the payload, read back every byte, rename with dated backups, then verify final sizes. RETR now uses the known payload length. The collector is bounded to 3 full-file retries (L9330, L9361).
- Never loop FTP retries. `install_console_test_apps.py` now exits before making any change (L9476).
- Hardware evidence: `artifacts/console-test-app-results/20261016-003914-229-direct/` (L9327).

**Host issues:**
- WSL hung. The fix that worked, after user approval, was a targeted `hcsdiag` kill of the WSL VM, because the service restart was denied (L9576-9581).
- Disk C: hit zero free space. `compress_archived_builds.py` applied NTFS compression and recovered about 5.8 GB (L9623-9631).
- Foreign SMG emulators often run on the host and contaminate timing.

**Research registry:** experiment decisions are indexed (see AGENTS.md: port-experiment-decisions.json). Docs per feature: NATIVE_*.md (for example NATIVE_WORLD_PACKETS.md, NATIVE_PROGRAM_RESIDENCY.md, NATIVE_AUDIO_*.md, NATIVE_PARTICLE_*.md), OLD_FAST_30FPS.md, ISO_SETUP.md.

## 6. Standing user directives and preferences

- **Audio only needs to be audibly close enough**, not 1:1 (16 Oct, L8936-8942, L8892). Do not chase small reverb or resampling differences. Crashes, dropouts and gross level/timing errors remain real defects. Keep the original mixer as a comparison option.
- **"If the DSP is faster, why not enable it?"** As a result, DSP is the default (L8846).
- **ONE startup application.** Benchmarks and probes go in the existing startup menu, with no duplicate apps or launchers (L9438, L9484).
- **A gain of "much more than 12.9%" is required.** No audio-only detours; prioritize structural native prep/draw/publication replacement (15 Oct, L10714, L10877-10880).
- The user prioritized two OS crashes on 15 Oct: one random, one while enabling an option (HEAT) (L10516).
- Never claim physical FPS from emulator or instruction counts. Never multiply the hardware FPS by emulator ratios (L9783).
- Shadow flicker is fixed, so make no more shadow probes. Do not poll pending hardware tests, and do not restart shared WSL without approval (L9640).
- Prefer headless, unattended testing. Preserve saves and assets, and do not touch console saves or settings.
