## 4. Architecture and engine facts

- **Audio**: the source synth runs 1 ms ADSR/control ticks, against the NDSP 4.89 ms block. A DSP block covers about 3.5 ms of elapsed time for each 5 ms of sound, which does NOT mean 70% CPU (L12042). There are 12-23 active voices, but only 3-8 are needed for the dry path. A dry-only DSP offload is insufficient because the master studio AUX A uses sndAuxCallbackReverbSTD at 0x3e2c90, and the source has 11 gains against 12 DSP mix entries plus 2 AUX buses (L12035-12041, L11476-11479). Of 1,472 static ADPCM samples, 1,174 stay compressed and 298 unaligned loops need PCM. The full PCM bank is 63 MB and mixed 34 MB, so no whole-bank residency (L11965-11974). NDSP channels 0/1 are reserved and 2-23 are usable. WaveBufClear is not a DSP ack. SDK Read/sync happens before the lock, so clear cannot be called from the game thread (L11885-11892, L11941-11945). SDK getRate returns a ratio, not Hz (L11859). On Old, audio runs on core0 and takes about 26% of instruction share (L12242); on New, audio sits on core2, not two idle graphics cores.
- **Native audio backend status**: DIRECT STEREO ONLY, experimental, not enabled in game. The CPU software synth is still fully active (L11578-11583, L11476).
- **Renderer**: prepared world/model plans, the prepared buffer owner and packed commands already exist; do not reimplement them (L12110-12112). Explicit GX_CMDLIST_FLUSH already avoids a full linear heap flush (L12240, L12560). Linked fh_renderer_sync is `bx lr`, not a real fence (L12558-12559). Native actor submission is synchronous, so matrices can be borrowed until the draw returns (L13642-13644). The current shared actor/HUD shader holds 511 of 512 instructions and all 96 float and 16 bool uniforms (L14163-14165). The pinned SDK AddFixed 32-bit shift loses attributes 8/9; the native layout works around it with a 64-bit permutation (L14136-14139). Water bool uniforms need SDK location 0x68, not index 0 (L15012-15014). The game uses SDK short enums (L15072-15073).
- **Original game**: modelInitMtxs takes the cached path when 2 <= joints <= 100. The native early actor return bypasses objSetupLightChannels, so the selected-light globals are stale (L13793-13799, L13956-13958). TEXnMTXIDX overrides the default PNMTX0 (Aurora shader.cpp:1093) (L14223). The movie THP has 576 frames and takes about 9.4 ms per frame in the emulator (L12554).
- **Memory**: Old normal heap is 50,331,648, linear 12 MiB under the new profile (previously 10,485,760), process 83,886,080, VRAM free 4,723,712. New heap is 71,303,168, linear 25,165,824. Typical Old Thorntail: heap about 42.13 M, linear free about 3.75 M. The CIA profiles are Old80/New124.

## 5. Tooling and workflow

- **Never blind-build root WIP.** Root contains unrelated renderer/VRAM WIP. Use the isolated archive builders (build_*.py) and pure patches, and do not double-apply patches to the latest snapshot. Never modify hardlinked archived libraries in place; deduplicate_archived_game_libraries.py hardlinks identical archives after a SHA proof (L11989-11991).
- Runners: `tools/run_old_fast_profile` (exact preset, cave or thorntail) (L12348). For audio, `test_audio_native_voice_device.py --backend lle --envelope --curves --paired --window --pause` plus `--delay 640`, where the flag needs a space (L11473-11474). Also `capture_native_audio_voices.py`, `analyze_arm_blocks --completed-window-only` (L12605), `host_timing_context.py`, which detects foreign emulators and compiles, and `capture/analyze_native_particle_state.py`.
- **Emulator**: a custom Azahar build with SVC11 for core ID (`build_azahar_audio_core_id.py`, L12289). For LLE it uses custom 21de0e plus private firmware 8e213f3e (L11544-11546). The near-exact earlier audio came from stock HLE, not firmware.
- **Gotchas**: foreign SMG compilation on the host invalidates timings repeatedly, so do not repeat contended boots. Emulator and instruction counts are never physical FPS. Full instruction profiling runs time out at about 155-185 s, and only completed 8-frame windows are valid. WSL failed (Ubuntu E_FAIL) when C: was low on space; Windows GCC works as a fallback (L11994-11997). matplotlib is missing on Linux, so use Windows.
- **FTP**: Old229 legacy ftpd lacks SIZE, so direct-collect uses one LIST plus listed lengths (L12840-12843). Repeated timeouts happen before login on both consoles. Do not loop retries; the user reopens FTP. Deploys stage files, read back the full bytes, back up, rename, and check the final size.
