## 4. Architecture/engine facts learned

**Memory budgets (New):**
- Normal heap 71.3MB with a 15% reserve, plus a 512KiB main stack (peak about 57KB). Peak usage is about 57.0MB.
- Linear 25.2MB, with 6-9MB minimum free.
- VRAM 6.29MB, 3.6-4.8MB free.
- Scene caches: 4MiB CPU / 6MiB GPU scene admissions, 7MiB compressed scene cache window, 64MiB scene-file cap (L26752).
- Prepared-texture staging 11MiB; texture snapshots 2 to 4MiB.

**Memory budgets (Old):** normal plus stack about 40MB of 48.2MB. Linear headroom is about 1MiB, only a few KB above the 1MiB guard (L29629, L29806).

**PICA rules:**
- Vertex buffers need explicit padding to the full stride (L29251).
- TEXUNIT1 corrupts with L4 textures in VRAM (L26877).
- CPU stores into VRAM crash on hardware (probe DFSR fault). Use GX memory fill instead (L28780).
- The GPU inverse-normal path times out on hardware (L28733).
- The uploaded shader is 486/512 instructions; it was 338 when vertex lighting was added (L30177). There are 96 float uniforms, 12 attributes and 16 booleans, all full.
- The user permits separate shader binaries (L28426).
- Never do raw depth readback.
- C3D_FrameEnd uses GX_CMDLIST_FLUSH with explicit range flushes; the whole-heap flush is not on the path. No 30 FPS submission cap exists: one physical window ran at 59.97 FPS submission cadence (L28130).
- FCRAM vs VRAM texturing measured 3.8x synthetic throughput, and a CPU copy in FCRAM costs 79.8% vs 3.8% in VRAM. This is strong evidence of contention, but not a gameplay multiplier (L27202).

**Game systems:**
- Engine68 first-person camera: yaw inertia, pitch proportional to stick, PADClamp (L26982).
- Enemy respawn timers are not saved on the card. All 11 Palace Hagabons respawn (delay 3600 playTime units) (L29641, L29737).
- Water stream 2 is mapBlockRenderWater with setupWaterCausticTev; engine19 uses setupWaterReflectionTev (L29856).
- Cloud models 1196/1199 lost their opaque vertices to LOD. RGBA4444 decode was wrong (L29934).
- The VAT5 UV error unit is /256, not /1024 (L28489).
- A shop is relocated to X[-11,-9], Z[-6,-4], layer 1 (L28650).
- The original enables 7 fixed attributes but initialised only slot 5 (L30126).
- Physical frame breakdown (ms/frame): scene 12.28, object render 5.95, worker wait 4.02, object update 3.0, VBlank 3.99, FrameBegin GPU acquire 1.99, reflection/particles 1.48 (L26707). GPU pending 11.6ms overlaps the CPU, so don't add it to the total.
- VBlank is an explicit main-thread wait after present. A deferred-END / pipelined presentation is not implemented and needs an ownership audit (L26690).
