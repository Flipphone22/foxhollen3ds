# Active lights in native diffuse maps

11 October: implemented and checked locally. Normal `43049ce63b9b` and replay
`418b3032dc93` are **not deployed**. LIGHT MAPS remains opt-in, OFF by default.
This reduces unnecessary shader and uniform work; it does not establish a
frame-rate gain, meet the feature's CPU budget, or repair the reported white
Arwing, disappearing trees, fur or shadow defects.

The previous map shader computed eight lights even when the source selected
fewer. Eight Boolean gates now skip inactive light calculations. The owner
publishes only active position/colour rows, while always publishing all gates.
Ambient, original unnormalized mesh normals, light order, arithmetic and final
clamp are unchanged. No approximate temporal reuse, CPU vertices, extra pass,
worker or image allocation was introduced. A 36-byte histogram records counts.

Every map update in the New palace check selected two lights. That changes
float-uniform publication from17 rows to5. Static control-flow counting gives
33 executed shader instructions instead of73 in this case, including branches;
this is not a GPU cycle measurement. With all eight lights, branches instead
increase the count to81. The stored map program is81 instructions,18 float
registers and8 Booleans; its containing material program is304/512 instructions.
The main511 and fur214 programs are unchanged.

Pinned Melee program-binding ownership and pinned citro3d `base.c`/`uniforms.c`
were consulted. Boolean writes follow `C3D_BindProgram` and use SDK dirty-state
publication. Existing ordered target publication, auxiliary-owner invalidation,
target sharing and retirement remain intact. No raw-register bypass was added.

The exact old and new linked map entries run identically over332,928 vertices
in Azahar's float24 interpreter, spanning0..8 lights, view/model offsets, border
normals and clamps. Maximum error against the original-source oracle is
0.0000738501549. Inactive new colour uniforms contain deliberately incorrect
values, testing isolation from other shader owners. Wrong light masks, missing
clamping and normalized-normal mutations fail. The older map-depth mutation
remains below the test tolerance and is not claimed detected. An initial mutant
used unsupported inverted-IFU syntax; it was corrected before acceptance.

Actual-owner ASan/UBSan tests pass301,290 slot checks,100 lifecycles and100,000
partial/random updates. Each map draw checks all eight Boolean writes and
exactly1+2*active float rows. Lifetime and missing-publication mutants fail.
Existing exact slot sharing is preserved; its savings are not new to this change.

Three serial, silent, isolated headless runs passed state/save/drain/owned-exit
checks. New and Old ON frame1410 images were inspected: world, Krystal,
EarthWalker, creatures/glows and HUD remain present. They are not complete
original-image comparisons or a reproduction of the user's Thorntail defects.
