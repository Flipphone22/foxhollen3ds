# Work in progress (not built)

Unfinished native code that is not part of the shipping build. Nothing in this
directory is compiled by `tools/build_native.py`; it may not compile against the
current sources. Main areas: on-device actor height fog preparation
(`install_actor_fog*`), effect and geometry hint installation, bump/directional
lighting, rigid bounds, shadow spans and shared PICA shaders.
